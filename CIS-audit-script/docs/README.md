# CIS Security Auditor

This is a simplified security auditing tool that checks Windows and Linux systems for common security vulnerabilities based on CIS benchmarks.

## Project Structure
- **src/**: Python source code (GUI and Engine)
- **scripts/**: PowerShell scripts for system checks
- **docs/**: Documentation and guides
- **bin/**: Compiled executable (for Windows)

## How to run
Run the Python script directly:
```bash
python src/main.py
```
Or run the executable in the `bin/` folder.
